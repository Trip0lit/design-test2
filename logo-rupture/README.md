# Logo RUPTURE

Version numérique (vectorielle) du logo dessiné à la main.

- Le **R** est un bonhomme : la boucle du R forme la tête (avec un œil), le fût et la jambe du R forment les jambes, un bras tient la loupe.
- Le **U** est la loupe dans laquelle le bonhomme regarde.
- `PTURE` complète le mot.

| Fichier | Usage |
| --- | --- |
| `rupture-logo.svg` / `.png` | Couleur encre bleu nuit `#1b2559` |
| `rupture-logo-black.svg` / `.png` | Noir |
| `rupture-logo-white.svg` / `.png` | Blanc, pour fonds sombres |

Les SVG sont la source ; les PNG (1640×640, fond transparent) en sont des exports.
